# 社区版本与发布范围

## 2.1.0-community.1 · 2026-10-04

基于 2026-10-03 开发板阶段的最终基线整理，保留当时的 Python / SQLite 实现。此次仅补充跨设备部署、清理部署信息、统一版本号、停用危险的旧恢复脚本并加入发布检查，不引入后续商业版本功能或其 Git 历史。

包含：FDSN / SeedLink 采集、PNSN / REAL / 网格定位、BM1684X 批量 NPU 适配器、参考目录与演播、三维地图、人工复核、Markdown 目录分析、本地或在线兼容模型接口、公开浏览与管理员后台。

不包含：后续专用 Mac mini Metal / MLX 部署、模块监管及升级恢复体系、PostgreSQL / WAL 恢复、持久消息总线、存储后端抽象、缺测补取体系、新版外置硬盘循环存储。社区版是单机基线，不能按大型生产集群的容量与恢复能力使用。

## 发布规则

社区版独立维护，功能发布选择已完成验证的较早基线，始终与最新版保持代际差。安全与部署修复可以单独移植，不以版本差为由保留已确认的安全问题；没有承诺自动开放后续特定功能或固定日期。

公开仓库只接受经清理的快照及社区补丁。不要从私有仓库直接 merge、推送分支、`--mirror` 或 `--all`；它们可能公开无关历史。发布前检查暂存区文件、配置样例与提交祖先，运行 `python scripts/check_release_files.py --community`，并核验目标仓库。

本地环境、账号、密钥、运行数据、设备地址与私密说明不属于发布材料。NPU 模型和 SDK 按部署指南自行获取 / 编译，第三方算法及资源保留各自来源与许可，未因本次发布更改其授权条款。
