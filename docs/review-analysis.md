# 人工复核与目录分析

## 波形复核

打开人工复核中的事件，点击“读取事件波形”。横轴为相对于发震时刻的秒数，纵轴为真实震中距；波形为原始 counts。

- 鼠标放在波形区域滚动滚轮，以指针所在时间为中心放大或缩小。底部滚动条平移时间窗，“重置视图”恢复所选完整时间窗。
- 点击某台的波形或台站名称，打开该台 Z/N/E 三分量独立窗口。窗口同样支持滚轮、时间滚动条和增益。放大后重新读取当前范围的采样，细节充分时显示原始采样点；缺测保留断点。
- 登录后台后，选择 Pg、Sg、Pn、Sn、P、S；对应快捷键为 **Ctrl+1、2、3、4、5、6**，支持主键盘和数字小键盘。
- 点击波形放置新震相，或选中已有震相并拖动竖线改变到时；也可在“到时 UTC”中精确输入。点击“保存震相”写入，星号表示未保存草稿。
- 选中已有震相后点击“删除所选震相”。“取消修改”或第一次 Esc 丢弃草稿，未选中草稿时 Esc 关闭窗口。

保存、删除都需修改依据，保留审计和版本检查。遇到其他人已修改的版本会拒绝覆盖，刷新后重新选择。震相改变后事件回到候选状态；需要另行执行重定位并检查结果，保存震相本身不自动重算位置。公开访客可以查看和缩放，但不能修改标注。

## 目录分析助手

进入活动性分析，选择时间范围与目录来源，点击“开始本地分析”。右侧先显示排队/生成状态，完成后显示模型名称及 Markdown 报告，包括目录质量、活动性、限制和建议。标题、列表、表格、加粗等正常渲染；不执行模型输出的 HTML，且不加载模型输出中的图片。

固定问题报告以“时间范围 + 来源”缓存五分钟，所有访客共享同一任务；队列有界，重复点击不会重复占用 NPU。失败会显示提示，统计图表仍可使用。管理员可以修改问题或主动选择已配置的在线大模型，默认走本地模型。

模型只接收目录统计摘要，输入上限加输出预算严格小于 8000 tokens。Mac 配置开发板转发后，将本机目录摘要交给板上模型；开发板与检测任务共用 NPU 锁。不能从未核实的覆盖、缺失日期或混合震级标度推断活动性增强、b 值或未来地震。

模型输入不包含覆盖未核实的逐日序列，也不让小模型自行累加震级分箱；后端先计算 M≥4、M≥5 的已收录记录数。统计图仍保留原始逐日计数。默认报告限制为四个简短章节，达到服务端输出上限时页面明确提示可能不完整。小模型仍需人工核对，不能替代目录质量评估。

## 验证方法

- Python 测试覆盖六类震相、版本冲突与删除、窄窗真实采样、队列去重与容量、匿名报告权限、服务端转发认证、预算与截断提示。
- 前端数学测试验证鼠标锚点、平移边界、采样点对齐和缺测断点。
- Chrome 在隔离数据库中读取 SCEDC 2019-07-06 真实三分量波形，验证滚轮、点击打开单台窗口、六个快捷键和新增/拖动/删除后的 API 数据；未改动生产事件。
- 桌面与 390 像素手机检查单台窗口、公开分析按钮、Markdown 标题/列表/表格，以及禁用原始 HTML 和外部图片。
- 开发板真实 Qwen3.5-2B 已通过服务端转发分析 Mac 自己的目录；一次短报告实际使用 777 tokens，包含完整四节。此数字为单次验证，不是固定性能指标。
