# 三维演播地图

CesiumJS 1.146.0 负责 WGS84 坐标、相机和真实高程网格，React 管理视角、底图及演播偏好。主地图与区域地质卡片共两个场景，不为每条文字创建额外 WebGL 上下文。简洁地球（D3 正射球面投影）与平面地图（D3 Mercator）使用随应用分发的 Natural Earth / USGS 矢量数据，不创建 WebGL 场景。新浏览器默认简洁地球；已选模式保存在本机。公开归属、覆盖及精度说明见 `/map-sources.html`（仓库 `public/map-sources.html`）。

在演播工具栏点击“设置”，最前面的“地图显示”分组可选择简洁地球、平面地图或精细三维，以及震中巡游、固定区域、全球视角和三维底图。中心坐标与镜头距离紧随其后。地图画面不再常驻这些控制按钮；CesiumJS、Mapzen / Tilezen、NASA GIBS 等署名位于地图底边，手机横屏时位于底部播放栏上方，来源链接保持可用。

- 震中巡游：全球 → 100 km 斜视 → 全球，与事件时长同步；暂停保持镜头，系统减少动态效果设置得到尊重。
- 固定区域：浏览器保存中心经纬度及 25–20000 km 镜头距离，提供固定当前震中和中国区域按钮。
- 全球视角：相同已保存中心，固定 22000 km 距离；更换事件不改变相机。卡片仍跟随事件。
- NASA Blue Marble 卫星合成底图 / ASTER 地形晕渲可切换。不是实时卫星、岩性或断层数据。
- DEM：AWS Mapzen/Tilezen Terrarium，RGB 转米，再进行 65×65 双线性网格采样，级别上限 12，统一展示夸张 2 倍。保留负高程；Web Mercator 极区限制及垂直基准近似在公开来源页说明。
- 震中光柱/屏幕空间光晕是示意标记，不表达地震能量、震源深度或传播速度。局部图不是三维地质反演。

## 运行资源

浏览器端最多 25 fps 主场景 / 10 fps 卡片，按需渲染；不可见或后台页面暂停绘制。移动端限制分辨率、地形细节和瓦片数量。共享 96 个已解码网格的缓存、最多 6 个高程下载，不使用 NPU。卸载销毁 WebGL、监听器和帧循环。

`/api/map/tiles/{kind}/{z}/{x}/{y}` 是固定来源代理，只允许三种图层及合法级别/坐标，不接收任意 URL。8 路上游并发、64 个去重下载上限、每图 2 MB 限制、20 秒网络超时、256 MB 磁盘缓存、30 天内部有效期，失败退避 30 秒。公共图片可由浏览器缓存 7 天；其它 API 仍保持 no-store。下载不经过数据库热路径。端点无需登录，管理接口权限不变。

`npm run dev/build` 从安装的 Cesium 包复制 Workers/Assets/ThirdParty/Widgets 到忽略的 `public/cesium`。构建后随 `dist/cesium` 一起部署，FastAPI 挂载 `/cesium`。Cesium 引擎只在选择精细三维时动态加载（约 1.1 MB gzip），目录界面不加载它。无需云密钥或新增后端依赖。

## 坐标与显示约定

地表纹理、地形几何、台站及震中标记统一由 Cesium 使用 WGS84 / EPSG:3857 变换；无单独的纹理经度偏移。镜头换事件走最短经度方向，中心归一到 ±180°。震中 HTML 光晕使用场景投影坐标并做椭球背面遮挡，不显示背向观察者的事件标签。台站和目录点按已加载 DEM 高度贴近地表；地形异步到达后刷新高度。极区以纯色椭球盖补齐未覆盖部分，不能解读为极区实测地形。

## 验证记录（2026-10-03）

- 真实 AWS Terrarium、NASA Blue Marble 和 ASTER 瓦片在本机及开发板网络均返回有效图片；本机浏览器同时加载真实地球和地质卡片的高程网格。
- 后端 50 项测试通过，包括新增源白名单/瓦片坐标、去重与断开连接、错误载荷/尺寸上限、失败退避、磁盘预算、公开缓存与后台隔离；3 项相机状态测试加入 CI。
- Chrome 实际页面检查：全球与区域锁定、更换事件、19,000 → 约 100 km 巡游、暂停、卫星/地形切换、WebGL 上下文失效与重试、无 WebGL 降级。1440×900、390×844、844×390、1024×1366 视口无页面 JS 错误或横向溢出；截图核对了卫星纹理、富士山周围山地及手机卡片排布。
- 三维引擎增大首次静态资源下载（约 1.1 MB gzip），后续场景及底图按需加载；公网网关开启 JavaScript / CSS 压缩，保留现有 HTTPS 和后台同源校验。

公网窄带连接的精细地形会分级到达，不能把首张底图到达当作完整场景就绪。界面显示“正在细化地形与影像”，以 Cesium 可视瓦片队列清空作为就绪条件；固定和暂停时仍继续处理地形网格与影像加载。首轮下载后的重复巡游可复用浏览器和服务器缓存。


## 持久缓存与轻量模式

浏览器在 HTTPS 或 localhost 下自动注册 `/map-cache-worker.js`。精细三维仍是实际高程网格；两个轻量模式不请求 Cesium 引擎、Workers 或地形瓦片，区域地质背景也同步切换。无 WebGL 时精细三维可降级为球面投影。

地图缓存使用当前站点 CacheStorage：最多 128 MB / 1200 项，单资源最多 6 MB，30 天后重取，按保存顺序淘汰旧资源。只允许固定来源地图瓦片、两份矢量文件、带哈希的构建 JS/CSS 和 Cesium 静态资源；登录、管理参数、实时目录、HTML 和所有写请求均不缓存。浏览器配额不足或不支持缓存时正常走网络与已有服务端磁盘缓存。局域网普通 HTTP 使用服务器缓存；公网 HTTPS 支持浏览器持久缓存。缓存仅加速地图，不能离线提供实时震情。

演播设置显示本机已缓存数量与容量，可清理本机地图缓存。“保存全球概览”只预存全球 0–2 级卫星和高程瓦片及矢量图，共 44 项；详细区域随实际浏览保存，不下载海量全球高精度瓦片。地图缓存不影响账号、演播偏好或卡片布局。升级 Cesium 时必须同步升级 `public/map-cache-policy.js` 的缓存版本以淘汰旧的非哈希 Workers/Assets。实现依据 [Service Worker 生命周期](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)。

## 五卡片布局

真实波形、AI 事件解读、区域地质、地震科普、实时地震列表分别显示，默认全部开启。桌面可用顶部手柄移动、右下角手柄独立改变宽高，键盘方向键以 10 px 微调。位置以相对比例持久保存并限制在地图内，底部为播放操作留出空间；设置支持锁定和恢复默认布局。文本长于卡片时在卡片内滚动，真实波形按可用空间自适应。手机竖屏使用纵向布局，低高度横屏按播放进度切换五卡片，不套用桌面坐标；转回桌面恢复已保存位置。

其他符合筛选的地震以实心点叠加，主事件保持脉冲特效。演播设置中的“地图显示台站位置”同时作用于精细三维、简洁地球和平面地图。列表点击切换主事件，自动刷新不会重置手工卡片布局；列表、卡片内容和设置超高时可滚动。
