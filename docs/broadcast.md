# 地震演播与直播

首页地图右上角提供 **分布图 / 固定显示 / 动画展示**。固定显示保留工作台导航，展示当前事件、真实波形、AI 解读和区域资料，使用上一/下一事件切换。动画展示进入无侧栏、无工作台选项卡的沉浸式地图，默认每 40 秒切换事件，镜头转向震中并推进；新收到的近期速报优先插播。多条速报同时到达时有队列，新的速报横幅可立即切换。

演播设置可调整 20–120 秒时长、最低震级、目录来源、波形/AI/区域地质/地震科普/地震列表五张卡片（默认全部显示）、台站点位显示、动画与新速报语音。默认排除未复核候选事件；允许展示时明确标注候选。设置保存在当前浏览器。暂停冻结事件进度和镜头；固定显示不会被新事件自动抢走，仍显示速报提示。尊重系统“减少动态效果”。

进入直播画面可直接使用 `/?view=broadcast`。公开演播无需登录；后台配置独立在 `/admin` 登录。点击演播工具栏的全屏图标可再隐藏浏览器窗口栏；不支持浏览器原生全屏时保留沉浸式布局。手机竖屏纵向排列地图和卡片；低高度横屏保留全屏地图、左侧震情和右侧信息卡，随播放进度展示波形 / 地震列表 / AI / 区域地质 / 地震科普，也可手动固定卡片。旋转屏幕不重置播放。退出演播返回工作台。可在 OBS 中采集这个浏览器窗口；本系统不自动向直播平台开播。

## 数据语义与来源

- 全球目录：[USGS M2.5+ 过去一天](https://earthquake.usgs.gov/earthquakes/feed/v1.0/summary/2.5_day.geojson)。中国及中国地震台网发布的境外事件：[中国地震台网](https://www.ceic.ac.cn/)，当前网页实际使用的公开数据文件为 `/data/data.json`。北京时间转换为 UTC，保存原始时间与事件 ID。
- 独立任务约每 30 秒拉取两种目录，浏览器每 3 秒接收通知。本地检测每 3 秒检查新增记录。**速度取决于源站发布和网络，本功能不是地震预警。** 不把原始发震时间当作本系统收到速报的时间。
- 演播回放最近 7 天已收录事件，最多 100 组。初次导入不触发海量新速报；历史事件、人工录入历史目录、既有事件参数修订不会伪装为新发生事件。只有新收到且发震时间在近 2 小时内的事件插播。
- 通知使用 SQLite 持久序号，刷新页面从当前游标开始；暂时断线可补收。回放始终标识“近期回放”，插播标识“新收到速报”或“候选待复核”，显示接收时间。
- 不同来源在 60 秒、80 km、震级差不超过 0.8 的情况下进行展示层合并，避免同一地震重复轮播；这是启发式归组。原始目录记录仍分别保留，科学分析不可把展示归组当作关联结论。按单一来源筛选会使用该来源的原始记录。
- 波形自动请求最近的 4 个不同台站、展示最多 3 个垂直分量，窗口发震前 20 秒至发震后 580 秒，优先本地连续记录，再读公共 FDSN。纵轴按实际震中距定位，横轴为相对发震时间；各道去均值、分别归一化，单位 counts。**有波形不代表已确认该事件震相**，不生成虚拟波形或未经拾取的 P/S 标记。缺数和近期数据尚未发布会明确显示。
- 背景地图为 Natural Earth；板块边界文件来自 [USGS MapServer](https://earthquake.usgs.gov/arcgis/rest/services/eq/map_plateboundaries/MapServer)，使用完整分页下载的 1,175 个要素，2026-10-02 缓存，归属说明 Bird (2003)、DeMets et al. (2010)。橙色脉冲是示意动画，不表示波传播速度、烈度或到达倒计时。

## 模型来源与区域地质

演播默认使用本地小模型。管理员在 `/admin` → 系统与模型 → “演播 AI 来源（解读 / 科普）”选择本地或在线模型；该选择不出现在公开演播设置。在线模式使用后台配置的 OpenAI 兼容接口和模型，密钥由部署环境提供。必须先填写在线接口和名称才能保存在线模式。开发板使用 Qwen3.5-2B，并与震相检测共用 NPU 文件锁。请求输入按 UTF-8 字节数保守估算上下文上界，总预算严格小于 8,000 tokens；输出最多 650 tokens（开发板配置 512）。

后台有界队列最多 8 个解读、6 个波形任务；模型解读单任务串行、默认每 60 秒最多开始一次推理。页面最多预取一个下一事件。结果按事件参数、版本、模型来源、接口、模型名称与预算分别缓存，修订后重新生成，普通轮播复用结果；临时失败允许重试。模型回答必须含完整的 `analysis/geology/science`，格式错误时保留核实过的来源资料和明确的失败状态。

区域背景通过 USGS 震中周边 500 km 主板块边界空间查询，以及 Wikipedia 的坐标检索、地质关键词索引搜索获得。附近条目按地理语义筛选，检索内容只作为资料、不能覆盖提示词。每条来源带链接和检索时间。科普使用 12 个来源明确的主题（震级/烈度、震源深度、P/S 波、目录与预测、震中与震源、定位、震级类型、地震仪、对数刻度、体波与面波、断层滑动、地点震动差异）。每个新准备的事件分配主题，最近 12 次分配不重复，重播与修订保留主题，选择记录持久存储且有 200 条上限。有限主题库轮换使用；后台选定的模型依据所选主题及事件参数生成内容，避免预测下一次地震和编造灾情或发震断层。USGS 板块资料是区域尺度，无法确认具体发震构造；在线资料有缺失时显示“暂不可用”。开发板所在网络对 Wikipedia 的访问可能超时，此时仍使用已获取的 USGS 构造资料。

工作站可设置 `SEISMICX_BROADCAST_RELAY_URL`，复用远端同一事件的公开缓存解读 API；远端本身将此项留空。目录统计模型转发另需两端配置相同的 `SEISMICX_MODEL_RELAY_KEY`，该密钥仅供后端互认，不发送给浏览器。具体变量见 `.env.example`。

## 运行和验证

新版本启动时自动建立通知和缓存表，不改变现有地震/震相表。更新 `backend/`、`dist/`、`public/plates.geojson` 后重启 API；采集器与 NPU 编目服务可保持运行。源站异常不会停止另一数据源，也不会停止台站采集；页脚显示各源状态。

本机曾触发 SQLite 3.51.1 的 Unix 并发开关连接锁死，已按 [SQLite 3.51.2 官方修复说明](https://www.sqlite.org/releaselog/3_51_2.html) 对 3.51.0/3.51.1 增加短元数据事务串行兼容处理，其余版本维持 WAL 并发。建议部署使用包含该修复的 SQLite 版本。该兼容处理覆盖在并发回归测试中。

```bash
.venv/bin/python -m pytest tests -q
npm run build
.venv/bin/python scripts/start.py --collector seedlink
```

2026-10-03 验收：本机 Python 3.12、开发板 Python 3.10 均通过 27 项测试；浏览器验证固定/动画切换、暂停、20 秒自动切换、来源筛选、设置和 Esc 返回。真实 M5.8 事件的板端 Qwen 调用使用 513 tokens（输入 351、输出 162，保守总预算 1,765），真实事件波形取得 IU.MA2、IU.YSS、IU.ADK。本机 480 次并发接口请求零失败，最慢 54 ms；同期开发板处理 198/198 台站，周期 36.84 秒，NPU 推理 0.92 秒。以上是现场抽测，并非长期容量承诺。

地图模式、持久缓存及卡片拖放操作见 [地图与卡片说明](3d-map.md)。

## 实时列表与地图点位

页面每 3 秒取得最新目录快照；列表按发震时间倒序，目录修订直接更新当前震情、列表和点位。动画播放时新收到且符合筛选的新速报优先切入，即使正在播放上一条速报也会切换；同批优先较新的发震时刻。暂停和固定显示不自动抢镜，恢复动画后处理待播速报。上游 USGS/CENC 仍受发布与后台目录轮询间隔影响，不等同于即时预警。

当前事件保留光晕/脉冲，其余符合演播筛选的地震绘制为实心点；台站默认显示，可在演播设置关闭。地震列表卡片默认显示，支持拖动、缩放、隐藏、内部滚动及点击切换主事件。时间参数标签和值不拆行，小屏超宽时局部横向滚动。横屏卡片选项也可横向滚动。

选择在线模型不会允许访客自行指定接口、模型或提示词。生成任务仍受队列、全局间隔和缓存限制；排队任务在模型配置变化后会被丢弃，正在生成的旧结果不会覆盖新模型的缓存。固定事件的模型摘要每 30 秒复核一次缓存来源，切换来源后自动获取新解读。本机使用开发板解读转发时，实际处理端的后台配置决定转发结果；本机选择在线来源时使用本机配置的在线接口。

本次增量验证：本机 56 项 Python 测试、7 项前端状态测试和生产构建通过。Chrome 实测五卡片、单行时间参数、列表滚动/点击、三种地图的台站开关及手机横竖屏；浏览器隔离数据验证新速报打断上一速报、列表新增和震级修订。独立临时数据库及 OpenAI 兼容测试服务验证后台来源保存/重载、实际 HTTP 请求和在线来源标注，未更改生产模型配置或调用付费在线服务。
