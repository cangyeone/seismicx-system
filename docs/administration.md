# 公开监测与后台管理

## 访问方式

- `/`：公开台站分布、实时状态、地震目录、事件波形和统计，直接访问。
- `/?view=broadcast`：无需口令的演播入口，适用于桌面、手机和 OBS 浏览器画面。
- `/admin`：管理员登录。人工录入、震相/震级校正、台站管理、检测和重定位、详细任务与系统配置需要登录。
- 公开地图的缓存 AI 解读、地质与科普可观看；自定义问题须登录。自动演播只能调用管理员选定的模型与固定提示词，受缓存、队列和最小间隔限制，访客不能选择接口或模型。
- 目录分析页允许访客触发固定问题的本地模型报告，仅支持页面列出的时间范围与来源。报告共享五分钟缓存、最多三项等待任务、单工作线程且启动间隔至少三十秒。自定义问题和在线模型仍需管理员会话；访客请求不能指定模型地址。

初次部署在应用目录执行 `python scripts/admin_account.py`，交互输入账号和密码（至少 8 位）。生产凭据不作为源码默认值。忘记密码时运行同一命令重置，所有旧会话立即失效。后台账号区支持同时更改用户名和密码；须验证当前密码，修改后重新登录。

## 参数与实际生效位置

| 配置 | 实际用途 | 生效时机 |
| --- | --- | --- |
| P / S 置信度 | PNSN 原始拾取分别按 Pg/Pn、Sg/Sn 筛选，保存原始与筛选 CSV | 新编目任务 / 下一 NPU 周期 |
| REAL 搜索参数 | `--real-R`：范围、深度、步长、事件分离、方位角空缺 | 新编目任务 |
| REAL 关联门槛 | `--real-S`：P/S/总数、双震相台站、发震时刻散布、P–S 间隔及窗口倍数 | 新编目任务 |
| REAL 并行度 | `--real-jobs` 与子进程 Numba 线程上限同步 | 新编目任务 |
| Vp / Vs 与速度名称 | REAL 速度及 skill 定位 CSV 速度模型 | 新编目 / 重定位任务 |
| 定位范围及网格 | skill `locate --method grid` 的深度、经纬/深度网格数、边界扩展和时间范围 | 新编目 / 重定位任务 |
| 推理周期 / 窗口 / 台站上限 / 延迟 | 连续边缘推理进程从共享数据库加载 | 下一 NPU 周期 |
| 目录轮询 / AI 间隔 | 独立公开目录同步 / 演播模型队列 | 下一轮任务 |
| 演播 AI 来源（本地 / 在线） | 解读、科普及区域摘要；仅管理员可选 | 新模型任务，摘要最多 30 秒刷新 |
| 名称 / 本地和在线模型接口与预算 | API、模型分析与自动解读 | 保存后 / 下一模型任务 |

配置持久化在 SQLite `state` 中，每次保存递增版本并记录审计。不同浏览器同时编辑发生版本冲突时拒绝覆盖，需重新载入。新任务保存完整配置快照，运行期间改参数不改变已提交任务。手动检测可填写单次速度覆盖，单次置信度下限只提高后台 P/S 门槛。重定位默认读取后台定位参数。

置信度下限为模型原始拾取下限 0.1。关联网格最多 50,000 点、定位网格最多 30,000 点，NPU 时间窗必须比周期至少长 30 秒。总模型上下文最多 7,900 tokens。提高台站上限不会自动增加订阅或提升硬件吞吐；应观察边缘推理页的周期耗时和实时延迟。

模型 API 密钥、NPU 文件路径、采集器分片/服务端地址及 FRP 密钥仍由运维环境管理；密钥不返回浏览器。本机演播配置了板端转发时，使用开发板的本地 Qwen 解读；模型配置应在实际执行该任务的开发板后台调整。本机与开发板具有各自的目录和运行设置，代码版本同步。

Mac 目录分析可使用同一开发板的 Qwen 模型：两端环境配置相同的随机 `SEISMICX_MODEL_RELAY_KEY`，Mac 的 `SEISMICX_BROADCAST_RELAY_URL` 指向开发板。该凭据只供后端互认，不是网站访问口令，不进入后台表单或前端包。分析使用发起端自己的目录统计，不用开发板目录代替本机目录。`/api/internal/llm` 无有效服务端凭据一律拒绝，开发板还限制并发与上下文，模型调用继续遵守 NPU 共享锁。

## 权限与会话

管理员密码仅保存带随机盐的 scrypt 摘要，会话令牌仅保存 SHA-256 摘要。Cookie 为 HttpOnly、SameSite=Strict，HTTPS 下 Secure，有效期 12 小时；写请求校验 CSRF 与同源 Origin。连续 10 次错误登录会按来源地址限制 5 分钟。退出、账号更新和密码重置撤销会话。公网必须由 HTTPS 反向代理转发，并正确传递原始协议和 Host。

服务器对管理读取及所有修改接口执行鉴权；隐藏按钮只是界面行为。匿名 API 不输出工作目录、任务载荷、后台配置或完整修改审计；公开目录仍保留来源、质量标记和算法版本。`SEISMICX_API_TOKEN` 已停用，旧 Bearer 口令不能绕过后台登录。API 文档位于已鉴权的 `/api/admin/docs`。

## 手机与横竖屏

桌面使用完整导航和多列参数，窄屏自动改为折叠菜单与纵向表单。波形和目录表格在各自容器内滚动。演播竖屏使用全宽地图及纵向卡片；低高度横屏使用左侧震情、中心地球、右侧信息卡片。右侧按演播进度自动切换，也能选择波形、地震列表、AI 解读、区域地质或地震科普，旋转后继续当前事件。浏览器不支持原生全屏时仍可使用隐藏导航的沉浸式演播。

## 验证

`python -m pytest tests -q` 包含公开读/管理写权限、Cookie/CSRF、登录限制、账号更新会话撤销、隐私字段剔除、配置校验/冲突、快照保持、P/S 阈值和 skill 参数传递。前端以 `npm run build` 验证，浏览器还须检查匿名浏览、登录后保存并恢复参数、退出，以及手机旋转和信息卡切换。

“系统与模型”提供演播 AI 来源下拉框，默认为本地小模型。选择在线大模型前必须填写在线接口和模型名称；密钥仍由服务器部署环境中的 `SEISMICX_CLOUD_LLM_API_KEY` 管理，不回传网页。该选择不会进入演播设置或公共可写接口。更换模型/来源后摘要独立缓存，不把旧模型结果标成新模型生成。
